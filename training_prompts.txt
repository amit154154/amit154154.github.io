# ==========================================================================
# TINY AMIT — on-policy distillation prompt set
# Hand-authored visitor turns for LFM2.5-230M in the Playground chat widget
# on amit154154.github.io.
#
# FORMAT
#   One prompt per line. Blank lines and lines starting with # are ignored.
#   Section headers look like:  ## category  weight=N
#   Multi-turn prompts use " || " between turns (see the followups section).
#   Text is intentionally lowercase / typo'd / fragmentary where real people
#   type that way. Do not clean it up — that texture is the point.
#
# WHY THIS DIFFERS FROM THE GENERATED SET
#   1. Page context. The visitor has the portfolio open. They ask about the
#      thing training in the hero, the koala, the games, the 210 MB download.
#      Abstract categories never produce these, and they are a large share of
#      real traffic for a chat sitting inside a toy box.
#   2. Low-effort turns exist. "hi", "test", "?" is what a real widget gets
#      first, more than any well-formed question. The model has to be good at
#      these or the first impression is the bad one.
#   3. Failure-surface weighting. A 230M model does not break on "where does
#      Amit work". It breaks on vague asks, compound asks, false premises,
#      questions outside the dossier, and anything tempting it into markdown
#      or a nine-sentence ramble. Those categories are over-weighted here on
#      purpose: on-policy distillation is worth the most exactly where the
#      student is currently wrong.
#   4. The leak rule is relaxed, deliberately. "Never state a fact from the
#      fact sheet" bans the natural phrasing a visitor uses while reading the
#      page ("i see he was at reality defender, what did he do there?"). For
#      a TRAINING prompt set this does not matter: the student is learning to
#      respond, not to guess a hidden answer. Keep the strict no-leak rule
#      for the held-out EVAL set, where a self-answering question really is
#      worthless. What is still avoided here is a question whose answer is
#      entirely contained in itself.
#
# WEIGHTS are rough sampling shares, not counts. Total 100.
# ==========================================================================
